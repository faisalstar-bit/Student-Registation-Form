# Student Registration Form

A simple and beginner-friendly Student Registration Form built using **HTML5 and CSS3**. This project demonstrates the use of HTML form elements and basic CSS styling.

## 📌 Features

- Full Name, Email, and Password fields
- Date of Birth selection
- Gender selection using radio buttons
- Multiple skill selection using checkboxes
- Address input using a textarea
- Program selection using a dropdown menu
- Submit and Reset buttons
- External CSS stylesheet for styling

## 🛠️ Technologies Used

- **HTML5** — Structure and form elements
- **CSS3** — Styling and layout

## 📂 Project Structure

```text
student-registration-form/
│

```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Fill out the form to explore its features.
